来源标注：

## 课程目标

本资料包用于展示数据库课程知识库，内容为中文教学整理稿，覆盖关系模型、SQL、索引、事务、范式和实验要求。

## 关键主题

1. 关系模型使用表、行、列表达数据结构。
2. SQL 用于数据定义、查询、更新和权限控制。
3. 索引可以减少扫描范围，但会增加写入维护成本。
4. 事务通过 ACID 保证数据库操作的一致性和可靠性。
5. 范式用于减少冗余和更新异常。
6. 实验报告需要包含需求说明、表结构设计、SQL 截图和结果分析。

## 示例问答素材

问题：事务 ACID 分别是什么意思？

整理答案：Atomicity 表示事务中的操作要么全部完成要么全部回滚；Consistency 表示事务执行前后数据库满足约束；Isolation 表示并发事务之间互不干扰或按隔离级别受控干扰；Durability 表示事务提交后结果应持久保存。
