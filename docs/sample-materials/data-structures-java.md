# 数据结构与算法 Java 版资料包

来源标注：

- Open Data Structures: https://opendatastructures.org/

## 课程目标

本资料包用于展示 Java 数据结构课程的 RAG 知识库。内容覆盖数组、链表、栈、队列、树、哈希表和复杂度分析。

## 关键主题

1. 数组结构适合连续存储和快速随机访问。
2. 链式结构适合表达节点关系，但会带来额外指针开销。
3. 栈遵循后进先出，常用于函数调用、括号匹配、撤销操作。
4. 队列遵循先进先出，常用于任务调度、消息缓冲、广度优先搜索。
5. 哈希表通过哈希函数将 key 映射到桶位置，平均情况下查询效率接近 O(1)。
6. 树结构适合表达层级关系，平衡策略可以避免搜索退化。

## 示例问答素材

问题：哈希表为什么能接近 O(1) 查询？

整理答案：哈希表先通过哈希函数把 key 转换为数组下标，再在对应桶中查找元素。如果哈希函数分布均匀且负载因子控制合理，每个桶中的冲突元素较少，因此平均查询时间接近常数级。
