# Phase 3 工程加固

## 目标

提升项目的工程可信度、安全性、可测试性和部署体验。

## 计划范围

1. 权限真实化
   - 知识库 owner 从 JWT 当前用户读取。
   - 教师只能管理自己的知识库。
   - `PUBLIC / COURSE_ONLY / PRIVATE` 真正影响可见范围。
   - 管理员拥有审核和接管权限。

2. 安全配置
   - JWT secret 通过环境变量配置。
   - LLM API Key 不进入代码仓库。
   - 增加基础限流和调用配额。

3. 测试
   - 文档切片单元测试。
   - 问题路由单元测试。
   - RAG 检索单元测试。
   - 登录、上传、问答集成测试。

4. 可观测性
   - Spring Boot Actuator。
   - 文档处理成功率。
   - 平均检索耗时。
   - 平均生成耗时。
   - LLM 调用失败率。

5. 部署
   - `.env.example`。
   - Docker Compose 一键启动。
   - dev/prod profile 分离。

## 非范围

- 不在本阶段强行做 Kubernetes。
- 不拆微服务，除非单体已经稳定。

## 验收标准

- 后端测试通过。
- 前端构建通过。
- `.env.example` 可指导完整启动。
- 管理员看板能看到基础运行指标。
