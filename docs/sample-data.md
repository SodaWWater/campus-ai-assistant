# 真实资料库与样例数据说明

## 知识库设计

本项目内置四类知识库，用于展示一个真实校园 RAG 产品的资料组织方式。

### Java 程序设计与软件构造

- 真实来源：MIT OpenCourseWare 6.005 Software Construction
- 参考链接：https://ocw.mit.edu/courses/6-005-software-construction-spring-2016/
- 辅助来源：北京大学 Java 程序设计课程页
- 资料类型：开放课程、校内讲义、实验指导
- 演示问题：
  - Java 中规格说明有什么作用？
  - ArrayList 和 LinkedList 怎么选？
  - 单元测试为什么要覆盖边界条件？

### 数据结构与算法 Java 版

- 真实来源：Open Data Structures
- 参考链接：https://opendatastructures.org/
- 资料类型：开放教材、Java 数据结构笔记
- 演示问题：
  - 栈和队列的应用场景有什么区别？
  - 哈希表为什么能接近 O(1) 查询？
  - 二叉搜索树在什么情况下会退化？

### 数据库系统基础

- 真实来源：国家高等教育智慧教育平台课程信息
- 参考链接：https://higher.smartedu.cn/courses
- 资料类型：课程参考、本地整理讲义、实验说明
- 演示问题：
  - 索引为什么能提升查询速度？
  - 事务的 ACID 分别是什么意思？
  - 第三范式解决什么问题？

### 校园学习事务指南

- 来源：明华大学软件工程学院演示资料
- 资料类型：校内流程、课程规则、学习事务
- 演示问题：
  - 实验报告迟交会怎么处理？
  - 奖学金申请需要满足什么条件？
  - 毕业论文格式有哪些要求？

## 资料使用原则

- 系统展示真实来源链接和授权标签。
- 内置正文以中文二次整理资料为主，不大段复制开放课程原文。
- 引用卡片中展示“来源平台、资料类型、授权说明、原始链接”。
- 校内资料采用虚构学校“明华大学软件工程学院”，用于补齐业务闭环。
