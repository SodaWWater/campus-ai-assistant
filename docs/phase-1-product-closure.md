# Phase 1 产品闭环与页面真实感

## 目标

让系统看起来像一个真实校园知识库产品，而不是功能堆叠 Demo。重点补齐学生、教师、管理员三类角色的页面信息结构和演示闭环。

## 本阶段范围

### 学生端

- AI 问答工作台保留三栏结构：会话、对话、引用来源。
- 增强回答操作：复制、重新提问、反馈。
- 增强引用来源展示：来源平台、授权标签、匹配分数、片段内容。
- 增加推荐追问。

### 教师端

- 问题分析页从简单记录表升级为教学分析面板。
- 展示高频问题、资料引用、响应耗时、问答记录。
- 未命中问题先用低匹配/无引用记录近似展示，不新增复杂后端。

### 管理员端

- 文档任务页从普通表格升级为任务监控页。
- 展示处理状态、失败任务、文档来源、重试和删除。

## 非范围

- 不新增向量检索。
- 不新增 OCR。
- 不新增复杂问答质量打分模型。
- 不改变数据库主结构。

## 验收标准

- `npm run build` 通过。
- `mvn -q -DskipTests compile` 通过。
- 学生端能看到问答来源和推荐追问。
- 教师端能看到问答分析和记录。
- 管理员端能看到文档任务状态和处理操作。

## 风险与处理

- 如果缺少后端统计接口，前端先基于现有 `/chat/history` 和 `/admin/documents` 做派生统计。
- 如果后端没有真实反馈接口，本阶段只做前端反馈状态，不持久化。
